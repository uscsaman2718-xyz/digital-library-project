# 📚 Digital Library Management System

A web-based **Digital Library Management System** developed using **PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap**.

The system allows users to browse, search, read, and download books online. It also provides an administrative interface for managing books, authors, categories, and library data.

---

##  Project Overview

The Digital Library Management System is designed to provide a simple and user-friendly platform for managing and accessing digital books.

Users can explore available books, search for specific books, view book information, and download books.

The administrator can manage the library database by adding and managing books, authors, and categories.

---

##  Features

### 👤 User Features

- 🔐 User Login
- 📚 Browse available books
- 🔎 Search books
- 📖 View book details
- ⬇️ Download books
- 🗂️ Browse books by category
- ✍️ View books by author
- 🚪 Secure Logout

###  Admin Features

- 🔐 Admin Authentication
- ➕ Add new books
- ✏️ Manage book information
- 👨‍💻 Add and manage authors
- 🗂️ Add and manage categories
- 📊 Manage library records
- 🗑️ Delete library records
- 📚 Manage the digital book collection
